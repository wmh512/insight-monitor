# 识字课单词本

> 每天 10 个 JS/TS 基础单词，按天追加。面试前翻这本，比背八股有用。
> 用法：遮住右侧例子，看左侧能说出意思和用法的，才算认识。

## Day 1（2026-10-19）· 地基十词

### 1. let —— 可变的变量

贴标签的盒子，内容可以换。默认不用它，要改才用。

```js
let score = 60
score = 90 // ✅
```

### 2. const —— 不可变的变量

贴了封条的盒子，放了什么就不能换整个盒子（但盒子内部的内容可以改，如数组 push）。**默认都用它。**

```js
const name = '王钰赫'
name = 'other' // ❌ 报错
```

### 3. string / number / boolean —— 三种基本数据类型

| 类型 | 例子 | 说明 |
|---|---|---|
| string | `'北京'` | 文字，用单引号或双引号包着 |
| number | `22` | 数字，不带引号 |
| boolean | `true` / `false` | 真假，只有这两个值 |

坑：`'42'`（文字）和 `42`（数字）是两种东西，`'42' + 1` 得到 `'421'`，`42 + 1` 得到 `43`。

### 4. function —— 函数（机器）

把一类操作打包起来重复使用。原料叫参数，产品叫返回值。

```js
function add(a, b) {
  return a + b
}
add(3, 5) // 8
```

### 5. return —— 函数的出货口

函数执行到 return 立刻停工，把值交给调用方。没有 return 的函数返回 `undefined`（空）。

### 6. if / else —— 条件判断（岔路口）

```js
if (score >= 60) {
  console.log('及格')
} else {
  console.log('补考')
}
```

### 7. for —— 循环（重复干活）

```js
for (let i = 0; i < 3; i++) {
  console.log(i) // 0 1 2
}
```

三段式：`i = 0` 起点；`i < 3` 条件；`i++` 每次 +1。

### 8. 数组 [] 与 .length / .push() / [下标]

一排带编号的盒子，编号从 0 开始。

```js
const list = ['a', 'b']
list.push('c')   // 末尾添加 → ['a','b','c']
list.length      // 3
list[0]          // 'a'（第一个，不是第二个！）
```

### 9. 对象 {} 与点号取值

带名字标签的格子集合。

```js
const me = { name: '王钰赫', city: '北京' }
me.name   // '王钰赫'
me.age    // undefined（没这个格子，不报错）
```

### 10. === / !== 与 && / || / !

| 符号 | 名字 | 例子 |
|---|---|---|
| `===` | 严格相等（类型+值都一样才真） | `'42' === 42` → false |
| `!==` | 严格不相等 | `42 !== 41` → true |
| `&&` | 与（两边都真才真） | `true && false` → false |
| `||` | 或（一边真就真） | `true || false` → true |
| `!` | 非（真假颠倒） | `!true` → false |

铁律：**永远用 `===`，不用 `==`**。`==` 会偷偷转换类型（`'42' == 42` 是 true），是混乱之源。

## Day 2（2026-10-19）· 常用十词

### 11. typeof —— 类型探测器

`typeof 42` → `'number'`。坑：`typeof null` → `'object'`；数组也是 `'object'`（判断数组用 `Array.isArray`）。

### 12. 模板字符串（反引号 + `${}`）

```js
`我是${myName}，今年${myAge}岁`  // 变量直接插进文字
```

必须用反引号（Esc 下面那个键）。项目里 `资源加载失败: ${url}` 就是它。

### 13. 可选链 `?.`

`user.address?.city`——address 不存在时返回 `undefined`，不报错。读“可能不存在的属性”时用它。

### 14. 空值合并 `??`

`config.retry ?? 3`——左边是 null/undefined 才用右边。比 `||` 精确：`0 || 5` → 5，但 `0 ?? 5` → 0。

### 15. try / catch —— 试跑护栏

```js
try {
  JSON.parse('坏数据') // 炸
} catch (e) {
  console.log('抓住了:', e.message) // 走备用方案
}
```

SDK 的自我保护（guard）全靠这个结构。

### 16. throw —— 主动扔错误

`throw new Error('配置未初始化')`——发现问题主动炸。原则：**编程错误必须大声失败，不许静默**（config.ts 的 getOptions 就是）。

### 17. 箭头函数 `=>`

```js
const add = (a, b) => a + b // 等价于 function add(a, b) { return a + b }
```

函数的简写。项目里 `n => n * 2`、`data => captured.push(data)` 全是它。

### 18. map —— 加工流水线

`nums.map(n => n * 2)`——每个元素加工一遍，得到等长新数组。error.ts 里 `.map(line => line.trim())` 就是它。

### 19. filter —— 筛子

`scores.filter(n => n >= 60)`——符合条件的留下，得到新数组。

### 20. slice —— 切片刀

`list.slice(0, 3)`——取第 0 到第 3 个（**不含 3**）。error.ts 的 `stack.split('\n').slice(0, 3)` 就是它：**指纹算法取堆栈前 3 帧的实现现场**。
