# Insight Monitor 使用说明

> 给想接入自己网页的老师/同学看——**不需要任何技术基础**，5 分钟读完。

## 这是什么

一个给网页用的「体检仪」。

把它接入你的网页后：你的网页什么时候出了错、哪里出了错、打开有多快——它自动记录下来，随时能查。不用等用户来投诉，不用猜「我电脑上是好的啊」。

## 什么人适合用

| 你是谁 | 对你有什么用 |
|---|---|
| 有课程设计网页的同学 | 交给老师之后出了问题能第一时间知道，不用等挨骂 |
| 有博客 / 作品集页面的同学 | 页面挂了自己不知道？它告诉你 |
| 社团 / 学生组织 | 活动报名页、海报二维码落地页——出了错影响的是真实的报名人数 |
| 老师 | 课程项目页、教学演示页，学生端出问题有据可查 |

## 它能发现什么

| 类型 | 具体包括 | 说人话 |
|---|---|---|
| 代码错误 | 页面 JS 报错、按钮点了没反应背后的异常 | 「你的代码在某台设备上炸了」 |
| 资源加载失败 | 图片裂了、样式表丢了、脚本没加载上 | 「你页面缺了块东西」 |
| 请求失败 | 没有被正确处理的网络请求报错 | 「有个请求挂了没人管」 |
| 打开速度 | 首屏多久显示出来、主要内容多久加载完 | 「你的页面在手机上打开要 3 秒」 |
| 出错环境 | 什么浏览器、什么设备、什么时间出的错 | 「这个问题只有安卓手机上有」 |

> 注意：目前只支持**普通网页**，暂不支持微信小程序。

## 一个例子（一听就懂版）

小李的课程设计是「二手书交易平台」，作业已经交了。

某天晚上，老师用手机打开页面，点了下「发布商品」——**没反应**。老师在自己电脑上试，好的。小李也懵了：我电脑上明明是好的啊？

如果他的页面接入了监控，第二天他打开后台会看到：

```
新错误 × 3 次
Uncaught TypeError: Cannot read properties of undefined (reading 'price')
位置：publish.js 第 47 行
设备：Android · Chrome 142 · 屏幕 1080x2400
时间：昨晚 21:30 - 21:47
```

三行信息，秒懂：发布按钮在安卓机上因为某个字段为空炸了，电脑上不炸是因为表单默认值不同。**十分钟修好。**

没有监控的日子，这个问题要等老师再次访问、或同学告知，你才知道——而且你手里没有任何线索。

## 怎么用

### 被监控的人（你的老师/同学/用户）

**什么都不用做**——照常打开网页就行。出错了会有人通知到你。

### 想接入自己网页的人

| 步骤 | 做什么 | 谁来做 |
|---|---|---|
| 第一步 | 把网页部署到网上（GitHub Pages 免费，5 分钟） | 你 |
| 第二步 | 把网页链接发给王铭赫 | 你 |
| 第三步 | 在你的页面里加 3 行代码 | 王铭赫 |
| 之后 | 出了错，系统自动通知；你也可以随时打开后台自己看 | 全自动 |

## 大家可能问的

**收费吗？**
免费。这是我的学习项目，但它是真能用的。

**会让我的网页变慢吗？**
监控代码压缩后 3.7KB（相当于一张小图片），异步加载，用户完全无感。

**会采集用户隐私吗？**
不会。只采集错误信息、页面性能、浏览器型号和屏幕大小这类匿名数据；不采集姓名、手机号、Cookie 内容。所有数据存放在我自己的服务器上，不做任何商业用途。
