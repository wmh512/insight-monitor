# 问题日志（Problem Log）

> 规则：卡住超过 2 小时的问题必须记录。
> 面试时被问「最难的问题 / 最有成就感的事」，答案全部出自这里。
> 每条记录 = 一个面试故事。

## 记录模板

```
### P0XX：一句话标题
- 日期：
- 现象：
- 环境：（浏览器 / Node 版本 / 系统）
- 排查过程：
  1) ...（做了什么，排除了什么）
  2) ...
  3) ...
- 根因：
- 解决方案：方案 A（选用，理由）／ 方案 B（弃用，理由）
- 量化结果：
- 关联 commit：
- 面试讲法：
  - 30 秒版：
  - 3 分钟深挖版：
```
