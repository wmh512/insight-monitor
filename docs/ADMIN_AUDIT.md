# 管理审计

## 记录范围

- 访问记录：登录成功、密码错误、退出登录。
- 操作审计：错误状态修改，包括对象不存在时的失败结果。
- 系统没有删除数据或账号设置接口，因此不虚构对应的审计事件。

## 数据安全

只保存事件、账号、IP、User-Agent、结果和必要的变更摘要。密码、Cookie、
Session ID、Token、原始请求体和原始响应均不得写入审计表。

审计接口与菜单仅对管理员开放。审计列表只读，筛选条件使用参数化 SQL。
错误状态与操作审计在同一事务提交，审计失败时业务更新一并回滚。

## 部署

先备份数据库，再执行 `packages/server/scripts/migrate-audit-logs.sql`，
然后部署服务端和后台并重启 `insight-api`。配置 `AUDIT_RETENTION_DAYS=30`
可显式指定保留期限；未配置时默认 30 天，每日自动清理。
